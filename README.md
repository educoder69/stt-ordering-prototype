# 🎙️ Voice Eats - AI Voice Ordering Prototype

A high-fidelity prototype of a voice-activated food ordering application. Built with **Vanilla JS**, **CSS Glassmorphism**, and the **Web Speech API**.

## ✨ Key Features
- **Voice Ordering**: Add items to your cart using natural speech.
- **Interactive Upsell**: Smart suggestions (e.g., "Make it a meal?") based on your order.
- **Soft Reset**: Seamless transitions between orders without reloading the page, preserving microphone permissions.
- **Glassmorphic UI**: A modern, premium design with Lucide icons and smooth animations.
- **QR Payment**: Simulated payment flow with a collection ticket system.

## 🛠️ Usage
1. Click **Start Ordering**.
2. Tap the microphone icon.
3. Say things like:
   - *"I want a spicy burger"*
   - *"Add some chicken nuggets"*
   - *"Can I get a coke?"*
4. Respond to the upsell: *"Yes"* or *"No"*.
5. Go to **Checkout** and simulate a payment.
